Keep your Mac awake
while AI does the work

An MCP server + CLI that stops your Mac locking mid-task while an AI assistant runs — then flashes the screen and pings you the moment it needs you. It wraps the caffeinate and osascript binaries that ship with macOS, so it works even on locked-down, MDM-managed Macs where apps like Caffeine or Amphetamine are blocked.

Five tools the assistant can call

stay_awake

Keep the Mac awake. presentation mode holds the display on and blocks the lock; compute mode keeps only the system awake for background jobs.

let_sleep

Release the assertion so the Mac can sleep and lock normally again.

awake_status

Report whether keep-awake is active (mode, PID, TTL) plus the live pmset assertions.

notify

Post a Notification Center banner with a message, title, subtitle, and sound.

flash

Flash every display a few times as a hard-to-miss visual alert.

Why it's different

Works under MDM

caffeinate is part of the OS, not a third-party app — it creates the same power assertion Keynote uses in presentation mode.

Fully automatic

Claude Code hooks keep the Mac awake while the agent works, flash when it needs you, and release the assertion when it goes idle or finishes.

Session-aware alerts

Banners name the project (e.g. "Claude · P001") so you can tell which of several running sessions is calling.

Network-free & safe

No network calls; every subprocess runs without a shell. Keep-awake always has a release path, so it never silently runs forever.
